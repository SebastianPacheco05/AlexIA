CONECTA TU ASISTENTE

AlexIA, en tu Alexa.

Configura tu skill desde la consola oficial. Tu contraseña permanece en Amazon.

  1. 1

    Abre tu skill en Amazon

    Inicia sesión directamente en Amazon Developer y abre tu skill de AlexIA. Debe tener su nombre de invocación y PreguntarIntent con el slot pregunta configurados.

    Abrir consola de Alexa
  2. 2

    Pega el endpoint HTTPS

    En Build → Endpoint, elige HTTPS, pega esta URL en Default Region y selecciona un certificado de una autoridad de confianza.

    Guarda el endpoint en Amazon. El enlace cambia al reiniciar un quick tunnel.

  3. 3

    Vincula el ID y prueba tu voz

    Copia el ID de la skill a Entorno → ALEXA_SKILL_ID y guarda los ajustes. En la consola de Amazon, activa Test → Development y prueba el nombre de invocación de tu skill.

Vincular mi usuario Alexa

Vincula esta identidad de Alexa con tu cuenta GitHub conectada. Primero desbloquea las integraciones y conecta GitHub.

AlexIA no solicita credenciales ni modifica tu cuenta.
